# Background clips

Drop real recordings here and the app uses them behind the flashcards. A kind
with no file falls back to our drawn animation, so you can add them one at a time.

| File          | What it should show                          |
| ------------- | -------------------------------------------- |
| `runner.mp4`  | Subway Surfers style endless runner gameplay |
| `parkour.mp4` | Minecraft parkour gameplay                   |
| `slice.mp4`   | Cutting sponge / kinetic sand ASMR           |
| `marbles.mp4` | Marble run / satisfying marbles              |

Tips: record on a phone held upright (vertical, 9:16), 15 to 30 seconds, no
sound needed (the app mutes it), saved as `.mp4`, and ideally under 10 MB each.
The clip loops, and each card starts it at a random moment.
